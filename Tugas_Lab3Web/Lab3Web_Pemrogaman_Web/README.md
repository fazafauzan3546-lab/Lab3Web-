# Lab3Web — CSS Dasar

Project ini meniru layout screenshot referensi dengan:
- latar putih dan garis tipis abu-abu di bagian atas;
- judul biru di tengah dan teks *Inline CSS* berwarna abu-abu miring;
- navigasi hijau;
- panel konten biru;
- tombol merah.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `Lab3Web_Screenshot` di VS Code.
3. Buka `index.html` melalui browser atau pilih **Open with Live Server**.
4. Pastikan `index.html` dan `style.css` berada di folder yang sama.
